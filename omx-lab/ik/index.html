1개념: 삼각형 하나로 줄여서 푼다

기호가 낯설면 → 상황 {n} FK의 막대 길이와 각도 방향을 먼저 보세요.

손을 수평으로 유지한다고 정하면(θ2+θ3+θ4 = 0) 문제가 쉬워집니다. 손목은 손끝에서 L3만큼 뒤에 있으니, 남은 일은 어깨–팔꿈치–손목 삼각형을 푸는 것입니다.

  1. 손목 위치: W = (공 x − L3, 공 z), 어깨에서 손목까지 거리 d = √(Wx² + Wz²)
  2. 코사인 법칙으로 팔꿈치 안쪽 각 γ와 어깨에서 본 각 β:
    cos γ = (L1² + L2² − d²) ÷ (2·L1·L2)
    cos β = (L1² + d² − L2²) ÷ (2·L1·d)
  3. 위팔 방향(수평에서 위로) φ1 = atan2(Wz, Wx) ± β. +는 팔꿈치가 위, −는 아래. 그래서 답이 2개입니다.
  4. 관절 각도로 바꾸기 (α = 20.1°는 위팔이 기울어 붙은 각):
    θ2 = 90° − α − φ1
    아래팔 방향 φ2 = φ1 ∓ (180° − γ), θ3 = −φ2 − θ2
    θ4 = −(θ2 + θ3) ← 손을 수평으로

d가 L1 + L2 = 0.2825 m보다 길면 삼각형이 만들어지지 않습니다. 그 공에는 손이 닿지 않습니다.
