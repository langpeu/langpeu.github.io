1개념: 관절 하나 = 스프링 + 브레이크 + 질량

기호가 낯설면 → 0 · 기초 개념: Kp·Kd·ζ(제타) 읽는 법

PD 제어기는 관절에 스프링(Kp)과 브레이크(Kd)를 달아 주는 것과 같습니다. 관절이 돌려야 하는 관성 I가 질량 역할을 합니다.

τ = Kp·(q목표 − q) − Kd·q

이 셋이 정하는 값이 감쇠비 ζ입니다. ζ가 1보다 작으면 목표를 지나쳤다가(오버슈트) 돌아오고, 작을수록 더 많이 지나치고 오래 흔들립니다.

ζ = (Kd + b) / (2·√(Kp·I))
오버슈트 = e−π·ζ/√(1−ζ²) × 100 %

b는 관절 자체의 점성 감쇠(ROBOTIS 모델 값 0.2 N·m·s/rad)입니다. 중력이 영향을 주지 않도록 바닥에서 도는 joint1로 실험합니다. 팔은 앞으로 뻗은 자세로 고정하고, 관절 마찰은 끕니다.
