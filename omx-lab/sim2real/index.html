1개념: 시뮬과 실물의 숫자가 다르다

기호가 낯설면 → 0 · 기초 개념: 시스템 식별

시뮬레이션은 모델에 적힌 질량·마찰·지연으로 계산합니다. 실제 로봇에 케이블, 카메라, 다른 그리퍼가 붙어 있으면 그 차이만큼 결과가 달라집니다.

해결 순서는 두 가지입니다.

  1. 시스템 식별: 실물에서 간단한 실험을 해서, 모델과 다른 값을 숫자로 알아낸다.
  2. 도메인 랜덤화: 정확히 모르는 값은 범위를 정해 시뮬에서 여러 값으로 학습·검증한다. 이때 범위가 실제 값을 포함해야 한다.

이 페이지의 '실물 로봇'은 실제 로봇 대신 쓰는 시뮬레이션입니다. 손끝에 모델에 없는 무게가 붙어 있는데, 그 값은 브라우저마다 무작위로 정해지고 숨겨져 있습니다. 상황 {n}의 중력보상 제어기(Kp 10, + 모델 g(q))를 그대로 씁니다.
